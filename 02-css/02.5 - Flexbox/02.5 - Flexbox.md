# 02.5 - Flexbox
## 1. ¿Qué problema resuelve Flexbox?

Supongamos que tenemos:
```html
<nav>
    <a>Inicio</a>
    <a>Explorar</a>
    <a>Transporte</a>
    <a>Perfil</a>
</nav>
```

Queremos algo así:

```text
┌───────────────────────────────────────────────┐
│ Inicio   Explorar   Transporte   Perfil       │
└───────────────────────────────────────────────┘
```

Podríamos intentar hacerlo con márgenes, posiciones, etc., pero sería complicado mantenerlo correctamente cuando cambie el tamaño de pantalla.

Flexbox nos permite decir:

> "Estos elementos forman parte de un grupo y quiero que CSS se encargue de distribuirlos."

## 2. Flex container y flex items

Tenemos:
```html
<nav class="navigation">
    <a href="/">Inicio</a>
    <a href="/explore">Explorar</a>
    <a href="/transport">Transporte</a>
    <a href="/profile">Perfil</a>
</nav>
```
Y:

```css
.navigation {
    display: flex;
}
```

El elemento:
```text
nav
```

se convierte en el **Flex Container**.

Mientras que:
```text
a
a
a
a
```

se convierten en **Flex Items**.

Visualmente:
```text
                FLEX CONTAINER
┌─────────────────────────────────────────────┐
│                                             │
│  ┌──────┐ ┌────────┐ ┌───────────┐ ┌─────┐ │
│  │ Inicio│ │Explorar│ │Transporte │ │Perfil│ │
│  └──────┘ └────────┘ └───────────┘ └─────┘ │
│                                             │
└─────────────────────────────────────────────┘
       ↑          ↑           ↑          ↑
       FLEX ITEMS
```

Esta distinción es **fundamental**.

## 3. `flex-direction`

Por defecto:
```css
.navigation {
    display: flex;
}
```

utiliza:
```css
flex-direction: row;
```

Es decir, los elementos se colocan horizontalmente:

```text
Inicio → Explorar → Transporte → Perfil
```

Podemos cambiarlo:
```css
.navigation {
    display: flex;
    flex-direction: column;
}
```

Ahora:
```text
Inicio
  ↓
Explorar
  ↓
Transporte
  ↓
Perfil
```

Los valores principales son:
```text
row
row-reverse
column
column-reverse
```

Para empezar, concéntrate principalmente en:
```text
row
column
```

## 4. Los dos ejes de Flexbox

Aquí viene uno de los conceptos más importantes.

Flexbox trabaja con dos ejes:
```text
             MAIN AXIS
        ───────────────────→

       ┌──────────────────────┐
       │                      │
       │       container      │
       │                      │
       └──────────────────────┘
                │
                │
                ↓
          CROSS AXIS
```

Cuando tenemos:
```css
flex-direction: row;
```

el eje principal es horizontal:
```text
MAIN AXIS
────────────────────────→
```

y el eje cruzado es vertical:
```text
      ↓
      │ CROSS AXIS
      │
      ↓
```

Pero si hacemos:
```css
flex-direction: column;
```

se intercambian:
```text
MAIN AXIS
    ↓
    │
    ↓

CROSS AXIS
──────────────→
```

Esto es **muy importante**.

No quiero que memorices:

> `justify-content` = horizontal
> `align-items` = vertical

porque eso **no siempre es cierto**.

Debes pensar:

> `justify-content` trabaja sobre el **eje principal**.

> `align-items` trabaja sobre el **eje cruzado**.

## 5. `justify-content`

Supongamos:
```css
.navigation {
    display: flex;
    justify-content: center;
}
```

Tenemos:
```text
┌─────────────────────────────────────────────┐
│                                             │
│        Inicio  Explorar  Transporte         │
│                                             │
└─────────────────────────────────────────────┘
```

Estamos centrando los elementos sobre el **main axis**.

Algunos valores importantes:
```css
justify-content: flex-start;
justify-content: center;
justify-content: flex-end;
justify-content: space-between;
justify-content: space-around;
justify-content: space-evenly;
```

Los tres que quiero que domines primero:
```text
flex-start
center
space-between
```

Por ejemplo:
```css
justify-content: space-between;
```

produce conceptualmente:
```text
┌──────────────────────────────────────────────┐
│ Inicio             Explorar            Perfil│
└──────────────────────────────────────────────┘
```

## 6. `align-items`

Ahora tenemos:
```css
.navigation {
    display: flex;
    align-items: center;
}
```

Esto trabaja sobre el **cross axis**.

Con `row`, sería el eje vertical:
```text
┌─────────────────────────────────────────────┐
│                                             │
│ Inicio   Explorar   Transporte   Perfil     │
│                                             │
└─────────────────────────────────────────────┘
                 ↑
              centrado
             verticalmente
```

Valores importantes:
```css
align-items: flex-start;
align-items: center;
align-items: flex-end;
align-items: stretch;
```

El más utilizado será probablemente:
```css
align-items: center;
```

Los elementos se distribuyen dejando el espacio disponible entre ellos.

## 7. El famoso `justify-content + align-items`

Esta combinación aparecerá **constantemente**:
```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

Si el contenedor tiene un tamaño definido, podemos centrar su contenido:
```text
┌─────────────────────────────────────┐
│                                     │
│                                     │
│              BOTÓN                  │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

Y ahora seguramente estás pensando:

> "Esto se parece bastante a centrar elementos dentro de un `ConstraintLayout`."

Sí, conceptualmente tiene cierta similitud, pero nuevamente quiero que pienses en **ejes de Flexbox**, no en traducir literalmente conceptos de Android.

## 8. gap

Hay otra propiedad que será muy importante en Viajia:
```css
.navigation {
    display: flex;
    gap: 24px;
}
```

Esto crea separación entre los elementos:
```text
Inicio   ←24px→   Explorar   ←24px→   Perfil
```

Es preferible a empezar a llenar todo de:
```css
margin-left
margin-right
```

cuando simplemente quieres establecer separación entre elementos de un grupo.

Y esto conecta directamente con el diseño que viste en Stitch:

```text
gutter: 24px
```

Ese tipo de espaciamiento se puede expresar naturalmente mediante `gap`.

## 9. Flexbox aplicado a Viajia

Ahora vamos a algo más cercano al proyecto.

Supongamos:
```html
<header class="header">
    <img class="logo" src="logo.png" alt="Viajia">

    <nav class="navigation">
        <a href="/">Inicio</a>
        <a href="/explore">Explorar</a>
        <a href="/transport">Transporte</a>
        <a href="/profile">Perfil</a>
    </nav>
</header>
```

Podríamos hacer:
```css
.header {
    display: flex;
    justify-content: space-between;
    align-items: center;
}
```

Conceptualmente:
```text
┌─────────────────────────────────────────────────────┐
│                                                     │
│ Viajia                  Inicio Explorar Perfil      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

Aquí ya estamos empezando a construir componentes similares a los que aparecen en el diseño de Viajia.

## 10. Flexbox también sirve para las tarjetas

Supongamos:
```html
<section class="events">
    <article class="event-card">...</article>
    <article class="event-card">...</article>
    <article class="event-card">...</article>
</section>
```

Podemos hacer:
```css
.events {
    display: flex;
    gap: 24px;
}
```

Resultado:
```text
┌────────────┐  ┌────────────┐  ┌────────────┐
│ Guelaguetza│  │ Jazz       │  │ Mezcal     │
│            │  │            │  │            │
└────────────┘  └────────────┘  └────────────┘
       ↑              ↑              ↑
              gap: 24px
```

Y aquí aparece una propiedad muy importante para responsive design:
```css
flex-wrap: wrap;
```

Con:
```css
.events {
    display: flex;
    gap: 24px;
    flex-wrap: wrap;
}
```

si ya no caben todas las tarjetas:
```text
Desktop:

┌──────┐ ┌──────┐ ┌──────┐
│  A   │ │  B   │ │  C   │
└──────┘ └──────┘ └──────┘


Pantalla más pequeña:

┌──────┐ ┌──────┐
│  A   │ │  B   │
└──────┘ └──────┘
┌──────┐
│  C   │
└──────┘
```

Sin que nosotros tengamos que calcular manualmente dónde colocar cada tarjeta.
