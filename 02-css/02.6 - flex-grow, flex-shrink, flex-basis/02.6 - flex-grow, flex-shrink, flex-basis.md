# 02.6 - `flex-grow`, `flex-shrink`, `flex-basis`
## 1. `flex-basis`

`flex-basis` establece el **tamaño inicial de un flex item sobre el main axis** antes de que Flexbox distribuya el espacio disponible.

Por ejemplo:
```css
.event-card {
    flex-basis: 200px;
}
```

Si tenemos:
```css
.events {
    display: flex;
}
```

estamos diciendo aproximadamente:

> "Considera inicialmente que cada tarjeta necesita 200px sobre el eje principal."

Con `flex-direction: row`, estamos hablando del ancho:
```text
             MAIN AXIS
────────────────────────────────────→

┌────────────┐ ┌────────────┐ ┌────────────┐
│            │ │            │ │            │
│   200px    │ │   200px    │ │   200px    │
│            │ │            │ │            │
└────────────┘ └────────────┘ └────────────┘
```

### Una diferencia importante con `width`

Cuando tenemos:
```css
.event-card {
    width: 200px;
}
```

estamos estableciendo explícitamente el ancho.

Mientras que:
```css
.event-card {
    flex-basis: 200px;
}
```

le estamos dando a Flexbox una **base para calcular la distribución del espacio**.

Por ahora quédate con:

> `width` = tamaño de ancho.

> `flex-basis` = tamaño base que Flexbox utiliza para distribuir espacio en el main axis.

Más adelante veremos casos donde esta diferencia se vuelve muy importante.

## 2. `flex-grow`

Ahora imagina que nuestro contenedor tiene:
```text
1000px
```

y tenemos tres tarjetas de:
```text
200px
```

Necesitamos:
```text
200 + 200 + 200 = 600px
```

Nos sobran:
```text
400px
```

Por defecto:
```css
flex-grow: 0;
```

Eso significa:

> El elemento **no crecerá automáticamente para ocupar el espacio sobrante**.

Entonces podríamos tener:
```text
┌────────────────────────────────────────────────────────────┐
│ ┌──────┐  ┌──────┐  ┌──────┐                              │
│ │ 200  │  │ 200  │  │ 200  │          espacio libre       │
│ └──────┘  └──────┘  └──────┘                              │
└────────────────────────────────────────────────────────────┘
```
Pero podemos decir:
```css
.event-card {
    flex-grow: 1;
}
```

Ahora estamos diciendo:

> "Si queda espacio disponible, puedes crecer para ocuparlo."

Si las tres tarjetas tienen:
```css
flex-grow: 1;
```
el espacio sobrante se distribuye entre ellas.

Conceptualmente:
```text
┌────────────────────────────────────────────────────────────┐
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐         │
│ │              │ │              │ │              │         │
│ │      A       │ │      B       │ │      C       │         │
│ │              │ │              │ │              │         │
│ └──────────────┘ └──────────────┘ └──────────────┘         │
└────────────────────────────────────────────────────────────┘
```

Las tres reciben la misma proporción del espacio adicional.

## 3. ¿Qué significa el número `1`?

Esto es importante.

Podemos tener:
```css
.card-a {
    flex-grow: 1;
}

.card-b {
    flex-grow: 1;
}
```

Ambas tienen la misma proporción:
```text
1 : 1
```

Pero podemos hacer:
```css
.card-a {
    flex-grow: 2;
}

.card-b {
    flex-grow: 1;
}
```

Ahora la distribución es:
```text
2 : 1
```

Es decir, A recibe **el doble del espacio adicional** que B.

No significa:

> "A mide el doble."

Significa:

> "Del espacio que sobra, A recibe dos partes y B una."

## 4. `flex-shrink`

Ahora vamos al problema contrario.

Supongamos:
```text
Contenedor = 500px

Tarjeta A = 300px
Tarjeta B = 300px
```

Tenemos:
```text
300 + 300 = 600px
```

pero solamente hay:
```text
500px
```

Falta espacio.

Por defecto:
```css
flex-shrink: 1;
```

Eso significa que los elementos **pueden reducirse para intentar entrar en el espacio disponible**.

Conceptualmente:
```text
Antes:

┌───────────────────────────────────────┐
│ ┌────────────┐ ┌────────────┐         │
│ │    300     │ │    300     │         │
│ └────────────┘ └────────────┘         │
└───────────────────────────────────────┘
              ↑
        no cabe


Después:

┌───────────────────────────────────────┐
│ ┌───────────┐ ┌───────────┐           │
│ │    ~250   │ │    ~250   │           │
│ └───────────┘ └───────────┘           │
└───────────────────────────────────────┘
```

Si hacemos:
```css
.card {
    flex-shrink: 0;
}
```

estamos diciendo:

> "No reduzcas este elemento automáticamente."

Entonces puede ocurrir que el contenido desborde el contenedor.

Esto será especialmente importante cuando hagamos layouts responsive.

## 5. La combinación de los tres

Ahora podemos escribir:
```css
.event-card {
    flex-grow: 1;
    flex-shrink: 1;
    flex-basis: 200px;
}
```

Esto significa, conceptualmente:
```text
                 FLEXBOX
                    │
                    ▼
             tamaño base = 200px
                    │
             ┌──────┴──────┐
             │             │
          ¿sobra?       ¿falta?
             │             │
             ▼             ▼
          grow          shrink
```

Es decir:
```text
flex-basis
    ↓
tamaño inicial

flex-grow
    ↓
¿puede crecer?

flex-shrink
    ↓
¿puede reducirse?
```

## 6. Existe una abreviación muy utilizada

Puedes escribir:
```css
.event-card {
    flex: 1;
}
```

En muchos casos prácticos esto se utiliza para decir:

> "Distribuye equitativamente el espacio disponible entre estos elementos."

Por ejemplo:
```css
.events {
    display: flex;
    gap: 24px;
}
.event-card {
    flex: 1;
}
```

Podríamos terminar con:
```text
┌────────────────────────────────────────────────────────────┐
│                                                            │
│ ┌────────────┐ ┌────────────┐ ┌────────────┐              │
│ │ Guelaguetza│ │   Jazz     │ │   Mezcal   │              │
│ │            │ │            │ │            │              │
│ └────────────┘ └────────────┘ └────────────┘              │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

Esta forma la vas a ver **muchísimo** en código real.

## 7. ¿Y qué tiene que ver esto con Viajia?

Bastante.

Imagina una sección de eventos:
```text
Desktop

┌─────────────────────────────────────────────────────────────┐
│ Eventos cercanos                                             │
│                                                             │
│ ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌───────────┐   │
│ │ Evento    │ │ Evento    │ │ Evento    │ │ Evento    │   │
│ └───────────┘ └───────────┘ └───────────┘ └───────────┘   │
└─────────────────────────────────────────────────────────────┘
```

Pero en móvil:
```text
┌────────────────────────┐
│ Eventos cercanos       │
│                        │
│ ┌────────────────────┐ │
│ │ Evento             │ │
│ └────────────────────┘ │
│                        │
│ ┌────────────────────┐ │
│ │ Evento             │ │
│ └────────────────────┘ │
└────────────────────────┘
```

Aquí empezamos a combinar:
```text
Flexbox
+
flex-wrap
+
flex-grow
+
flex-shrink
+
responsive design
```

Y posteriormente:
```text
CSS Grid
+
Media Queries
```

para construir layouts mucho más complejos.
