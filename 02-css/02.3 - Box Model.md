# 02.3 - CSS - Box Model
Hasta ahora has utilizado cosas como:
```css
.event-card {
    padding: 15px;
    border: 2px solid green;
}
```

Para entender exactamente qué está haciendo CSS, debemos visualizar la caja completa:
```text
┌──────────────────────────────────────┐
│               MARGIN                 │
│   ┌──────────────────────────────┐   │
│   │            BORDER            │   │
│   │   ┌──────────────────────┐   │   │
│   │   │       PADDING        │   │   │
│   │   │   ┌──────────────┐   │   │   │
│   │   │   │   CONTENT    │   │   │   │
│   │   │   └──────────────┘   │   │   │
│   │   └──────────────────────┘   │   │
│   └──────────────────────────────┘   │
└──────────────────────────────────────┘
```

Las cuatro partes son:
```text
Content
   ↓
Padding
   ↓
Border
   ↓
Margin
```

Vamos a entenderlas individualmente.

## 1. Content

Es el contenido propiamente dicho del elemento.

Por ejemplo:
```html
<h2>Guelaguetza</h2>
```

El texto:
```text
Guelaguetza
```

forma parte del **content**.

Si tenemos:
```css
.event-title {
    width: 300px;
}
```

dependiendo del modelo de caja que utilicemos, ese `300px` puede representar el ancho del contenido o del elemento completo. Esto lo veremos un poco más adelante con `box-sizing`.

## 2. Padding

El `padding` es el espacio entre el contenido y el borde.

Por ejemplo:
```css
.event-card {
    padding: 20px;
}
```

Visualmente:
```text
┌──────────────────────────────┐
│          padding             │
│   ┌──────────────────────┐   │
│   │                      │   │
│   │       contenido     │   │
│   │                      │   │
│   └──────────────────────┘   │
│          padding             │
└──────────────────────────────┘
```

Una forma de recordarlo:

> Padding = espacio interno.

Esto será muy utilizado en Viajia.

Por ejemplo, una tarjeta del diseño podría necesitar:
```text
┌─────────────────────────────┐
│                             │
│   Imagen                    │
│                             │
│   ┌─────────────────────┐   │
│   │ Título              │   │
│   │                     │   │
│   │ Descripción         │   │
│   │                     │   │
│   │ [ Guardar ]         │   │
│   └─────────────────────┘   │
│                             │
└─────────────────────────────┘
```

Ese espacio entre el contenido y el borde de la tarjeta puede conseguirse mediante `padding`.

## 3. Border

El border es el borde que rodea al contenido y al padding.
```css
.event-card {
    border: 2px solid green;
}
```

Tiene tres componentes:
```text
2px     → grosor
solid   → estilo
green   → color
```

También podemos escribirlos individualmente:
```css
border-width: 2px;
border-style: solid;
border-color: green;
```

Pero normalmente utilizaremos la forma abreviada:
```css
border: 2px solid green;
```

## 4. Margin

El `margin` es diferente al padding.

El margin representa **espacio externo** alrededor de la caja.

Por ejemplo:
```css
.event-card {
    margin: 20px;
}
```

Visualmente:
```text
        margin
   ↓              ↓

      ┌──────────────┐
      │              │
      │    tarjeta   │
      │              │
      └──────────────┘

        ↑          ↑
             margin
```

Una regla mental muy útil:

> Padding = espacio hacia dentro.

> Margin = espacio hacia fuera.

## 5. Los cuatro lados

Tanto `padding` como `margin` pueden configurarse individualmente:

```css
.event-card {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}
```

Pero CSS permite una sintaxis abreviada.

**Un valor**
```css
padding: 20px;
```

Significa:
```text
top    = 20px
right  = 20px
bottom = 20px
left   = 20px
```

**Dos valores**
```css
padding: 10px 20px;
```

Significa:
```text
vertical   = 10px
horizontal = 20px
```

Es decir:
```text
top    = 10px
bottom = 10px

left   = 20px
right  = 20px
```

**Tres valores**
```css
padding: 10px 20px 30px;
```

Significa:
```text
top    = 10px
left/right = 20px
bottom = 30px
```

**Cuatro valores**
```css
padding: 10px 20px 30px 40px;
```

El orden es:
```text
        TOP
         ↓
LEFT ← elemento → RIGHT
         ↑
       BOTTOM
```

Es decir:
```text
top
right
bottom
left
```

Una buena forma de recordarlo es **sentido horario**:
```text
          top
           ↓
left ←           → right
           ↑
         bottom
```

## 6. `width` y `height`

Ahora podemos agregar dimensiones:
```css
.event-card {
    width: 300px;
    height: 400px;
}
```

Pero aquí aparece uno de los conceptos más importantes del Box Model.

Por defecto, CSS utiliza:
```css
box-sizing: content-box;
```

Con `content-box`, si tenemos:
```css
.event-card {
    width: 300px;
    padding: 20px;
    border: 2px solid;
}
```

el ancho total no es simplemente `300px`.

Tenemos:
```text
Content = 300px
Padding = 20px + 20px
Border  = 2px + 2px
```

Por lo tanto:
```text
300 + 40 + 4 = 344px
```

La caja ocupa **344px** de ancho.

## 7. `box-sizing: border-box`
### ¿Qué problema resuelve `box-sizing`?

Tiene que ver con **cómo CSS calcula el tamaño final de una caja**.

Supongamos:
```css
.event-card {
    width: 300px;
    padding: 20px;
    border: 2px solid;
}
```

Podrías pensar:

> "La tarjeta mide 300px."

Pero **depende de** `box-sizing`.

Por defecto, CSS utiliza:
```css
box-sizing: content-box;
```

Con `content-box`, el `width` representa **solamente el área de contenido**.

Entonces tenemos:
```text
             300px
        ←─────────────→
       ┌───────────────┐
       │    CONTENT    │
       └───────────────┘
          ↑          ↑
        20px        20px
        padding     padding
```

Y además:
```text
border izquierdo = 2px
border derecho   = 2px
```

Por lo tanto:
```text
300 + 20 + 20 + 2 + 2
        ↓
       344px
```

La caja termina ocupando **344px de ancho**.

### ¿Qué cambia con `border-box`?

Si hacemos:
```css
.event-card {
    width: 300px;
    padding: 20px;
    border: 2px solid;
    box-sizing: border-box;
}
```

ahora `width: 300px` significa:

> La caja completa debe medir 300px.

Es decir:
```text
←────────────── 300px ──────────────→

┌────────────────────────────────────┐
│             BORDER                 │
│  ┌──────────────────────────────┐  │
│  │          PADDING             │  │
│  │   ┌──────────────────────┐   │  │
│  │   │       CONTENT        │   │  │
│  │   └──────────────────────┘   │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

Los `300px` incluyen:
```text
content
   +
padding
   +
border
```

Por lo tanto, el navegador calcula automáticamente cuánto espacio queda para el contenido.

En nuestro ejemplo:
```text
300px
- 40px padding
-  4px border
────────────
256px content
```

Así que:
```text
┌─────────────────────────────┐
│ border                      │
│ ┌─────────────────────────┐ │
│ │ padding                 │ │
│ │ ┌─────────────────────┐ │ │
│ │ │ content = 256px     │ │ │
│ │ └─────────────────────┘ │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
          300px
```

### ¿Y el `margin`?

Aquí hay una distinción importante:

**El margin no forma parte del `width`.**

Con:
```css
.event-card {
    width: 300px;
    padding: 20px;
    border: 2px solid;
    margin: 15px;
    box-sizing: border-box;
}
```

la caja mide:
```text
300px
```

pero tiene además:
```text
15px de margin izquierdo
15px de margin derecho
```

Por lo que el espacio que ocupa en el layout sería aproximadamente:
```text
15 + 300 + 15
       ↓
     330px
```

Esto es importante:
```text
              espacio total
←──────────────────────────────────→

   margin       caja       margin
     15px      300px        15px
       ↓          ↓           ↓
     ┌────┌────────────────┐────┐
     │    │                │    │
     │    │    TARJETA     │    │
     │    │                │    │
     └────└────────────────┘────┘
```

### ¿Por qué se usa tanto `border-box`?

Porque generalmente hace que trabajar con dimensiones sea mucho más intuitivo.

Imagina que Figma dice:

> Esta tarjeta mide **320px de ancho**.

Con:
```css
.event-card {
    width: 320px;
    padding: 24px;
}
```

Con `content-box`, terminarías con:

```text
320 + 24 + 24 = 368px
```

Y probablemente pensarías:

> "¿Por qué mi tarjeta es más grande que la del diseño?"

Con:
```css
box-sizing: border-box;
```

simplemente:
```text
tarjeta = 320px
```

y CSS se encarga de que padding y border quepan dentro de esos 320px.

Esto es especialmente útil cuando estás **traduciendo un diseño de Figma a CSS**.

### Por eso verás esto constantemente

En muchos proyectos encontrarás al principio del CSS:
```css
*,
*::before,
*::after {
    box-sizing: border-box;
}
```

El selector `*` significa:

> Todos los elementos.

Así que básicamente estamos diciendo:

> "Utiliza `border-box` como modelo de cálculo para todos los elementos."

Y esto hace que podamos trabajar de forma consistente con los tamaños.

### Un detalle interesante para Viajia

Tailwind CSS también utiliza `border-box` como parte de su configuración base/preflight.

Esto significa que cuando posteriormente pasemos de CSS tradicional a Tailwind, **este concepto seguirá siendo relevante**.

Por ejemplo, cuando veas algo como:
```html
<div class="w-80 p-4">
```

eventualmente tendrás que entender que:
```text
w-80
 ↓
width

p-4
 ↓
padding
```

y cómo ambos afectan al tamaño final del elemento.

Por eso estamos haciendo primero CSS **sin Tailwind**. No quiero que aprendas:

> "`p-4` significa padding."

Quiero que entiendas:

> "Padding modifica el espacio interno de una caja y, dependiendo de `box-sizing`, puede formar parte de las dimensiones especificadas."

Después Tailwind será principalmente **aprender otra forma de expresar conceptos CSS que ya comprendes**.

```html
<article class="event-card">
    <img
        src="imagen_guelaguetza.jpg"
        alt="Imagen de la Guelaguetza 2026"
        class="event-card-image"
    >

    <h2 class="event-title">
        Guelaguetza
    </h2>

    <p class="event-description">
        Festival cultural tradicional de Oaxaca
    </p>

    <button
        type="button"
        class="save-event-button"
    >
        Guardar
    </button>
</article>
```
```css
.event-card {
    width: 300px;
    height: 400px;
    padding: 15px;
    margin: 15px;
    border: 2px groove purple;
    box-sizing: border-box;
}

.event-card-image {
    margin: 15px;
}
```
