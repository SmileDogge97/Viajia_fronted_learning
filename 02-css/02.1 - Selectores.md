# 02.1 — Selectores CSS
Un **selector** determina qué elementos HTML serán afectados por una regla CSS.

Los primeros que debes dominar son:

## Selector de elemento
```css
p {
    font-size: 16px;
}
```

Selecciona todos los `<p>`.

## Selector de clase
```css
.event-card {
    padding: 16px;
}
```

Selecciona elementos con:
```css
class="event-card"
```

## Selector de ID
```css
#main-title {
    font-size: 32px;
}
```

Selecciona:
```html
id="main-title"
```

## Selector descendiente
```css
.event-card h2 {
    font-size: 24px;
}
```

Selecciona los `<h2>` que estén dentro de `.event-card`.

## Selector múltiple
```css
h1,
h2,
h3 {
    font-family: sans-serif;
}
```

Aplica la misma regla a varios selectores.

## Ejemplo ejercicio

el html
```html
<!DOCTYPE html>
<html lang="es">
    <head>
        <meta charset="UTF-8">
        <title>Viajia</title>
        <link rel="stylesheet" href="styles.css">
    </head>
    <body>
        <header></header>
        <main>
            <section>
                <article class="event-card" data-event-id="guelaguetza-2026">
                        <img src="imagen_guelaguetza.jpg" alt="Imagen de la guelaguetza 2026" class="event-card-image">
                        <h2 class="event-title">Guelaguetza</h2>
                        <p class="event-description">Descripción</p>
                        <button type="button" class="save-event-button">Guardar</button>
                </article>
            </section>
        </main>
    </body>
</html>
```

El css: styles.css
```css
.event-card {
    font-size: 26px;
    padding: 15px;
    border: 2px solid green;
}
.save-event-button {
    font-size: 16px;
}
.event-card-image {
    border: 2px dotted white;
}
.event-title {
    text-align: center;
}
.event-description {
    text-align: right;
}
```
