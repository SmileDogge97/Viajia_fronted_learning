# 02.7 - Grid
## 1. ¿Qué problema resuelve Grid?

Imagina una pantalla de Viajia como:
```text
┌───────────────────────────────────────────────┐
│                    Header                     │
├──────────────┬────────────────────────────────┤
│              │                                │
│   Sidebar    │          Contenido             │
│              │                                │
│              │                                │
├──────────────┴────────────────────────────────┤
│                    Footer                     │
└───────────────────────────────────────────────┘
```

Aquí tenemos simultáneamente:

- una columna para el sidebar;
- una columna para el contenido;
- una fila para el header;
- una fila para el contenido;
- una fila para el footer.

Grid está diseñado precisamente para este tipo de distribución.

## 2. Crear un Grid

Supongamos:
```html
<div class="layout">
    <header>Header</header>
    <aside>Sidebar</aside>
    <main>Contenido</main>
    <footer>Footer</footer>
</div>
```

Convertimos `.layout` en Grid:
```css
.layout {
    display: grid;
}
```

Al igual que con Flexbox:
```css
display: flex;
```

tenemos un **Grid Container**.

Sus hijos se convierten en **Grid Items**.
```text
layout
 │
 ├── header
 ├── aside
 ├── main
 └── footer
```

## 3. Definir columnas

Ahora podemos decir:
```css
.layout {
    display: grid;
    grid-template-columns: 250px 1fr;
}
```

Estamos creando dos columnas:
```text
       250px              espacio restante
┌────────────────┬──────────────────────────────┐
│                │                              │
│                │                              │
│                │                              │
└────────────────┴──────────────────────────────┘
    columna 1              columna 2
```

La segunda columna utiliza:
```css
1fr
```

### ¿Qué significa `fr`?

`fr` significa **fraction**.

Es una fracción del espacio disponible.

Por ejemplo:
```css
grid-template-columns: 1fr 1fr;
```

divide el espacio disponible en dos partes iguales:
```text
┌────────────────────┬────────────────────┐
│                    │                    │
│        1fr         │        1fr         │
│                    │                    │
└────────────────────┴────────────────────┘
```

Mientras:
```css
grid-template-columns: 1fr 2fr;
```

produce:
```text
┌──────────────┬───────────────────────────┐
│              │                           │
│     1fr      │           2fr             │
│              │                           │
└──────────────┴───────────────────────────┘
```

La segunda columna recibe el doble del espacio disponible que la primera.

Esto probablemente te resultará familiar después de haber visto:
```css
flex-grow: 1;
flex-grow: 2;
```

pero **no son exactamente el mismo mecanismo**.

## 4. Definir filas

También podemos definir:
```css
grid-template-rows
```

Por ejemplo:
```css
.layout {
    display: grid;

    grid-template-columns: 250px 1fr;
    grid-template-rows: 80px 1fr 60px;
}
```

Tenemos:
```text
              250px              1fr
         ┌──────────────┬─────────────────────┐
80px     │              │                     │
         │    Header    │       Header        │
         ├──────────────┼─────────────────────┤
1fr      │              │                     │
         │   Sidebar    │      Contenido      │
         │              │                     │
         ├──────────────┼─────────────────────┤
60px     │              │                     │
         │    Footer    │       Footer        │
         └──────────────┴─────────────────────┘
```

Pero observa algo:

**todavía no hemos dicho qué elemento ocupa qué posición**.

Eso lo veremos ahora.

## 5. Posicionar Grid Items

Podemos indicar:
```css
header {
    grid-column: 1 / 3;
}
```

Esto significa:

> El header comienza en la línea de la columna 1 y termina en la línea de la columna 3.

Visualmente:
```text
        │           │           │
        1           2           3

        ├───────────┼───────────┤
        │                         │
        │          HEADER         │
        │                         │
        ├───────────┼───────────┤
        │           │             │
        │  Sidebar  │  Contenido  │
        │           │             │
        └───────────┴─────────────┘
```

El header ocupa ambas columnas.

## 6. Una forma más sencilla: grid-template-areas

Para layouts como este:
```text
┌──────────────────────────────┐
│            Header            │
├────────────┬─────────────────┤
│  Sidebar   │    Contenido    │
├────────────┴─────────────────┤
│            Footer            │
└──────────────────────────────┘
```

Grid tiene una característica bastante interesante:
```css
.layout {
    display: grid;

    grid-template-columns: 250px 1fr;

    grid-template-areas:
        "header header"
        "sidebar content"
        "footer footer";
}
```

Después:
```css
header {
    grid-area: header;
}

aside {
    grid-area: sidebar;
}

main {
    grid-area: content;
}

footer {
    grid-area: footer;
}
```

El código prácticamente describe visualmente el layout:
```text
"header  header"
"sidebar content"
"footer  footer"
```

Para interfaces complejas puede ser extremadamente útil.

## 7. `gap` también existe en Grid

Al igual que Flexbox:
```css
.layout {
    display: grid;
    gap: 24px;
}
```

También podemos separar filas y columnas:
```css
gap: 24px;
```

o específicamente:
```css
row-gap: 24px;
column-gap: 16px;
```

Por ejemplo, una cuadrícula de eventos:
```text
┌──────────────┐ 24px ┌──────────────┐
│ Evento       │      │ Evento       │
└──────────────┘      └──────────────┘

       24px

┌──────────────┐      ┌──────────────┐
│ Evento       │      │ Evento       │
└──────────────┘      └──────────────┘
```

## 8. Grid para las tarjetas de Viajia

Aquí empieza a ponerse interesante.

Podríamos tener:
```html
<section class="events">
    <article class="event-card">Guelaguetza</article>
    <article class="event-card">Festival de Jazz</article>
    <article class="event-card">Feria del Mezcal</article>
    <article class="event-card">Día de Muertos</article>
</section>
```

Y:
```css
.events {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}
```

`repeat(3, 1fr)` significa:

> Crea tres columnas iguales.

Resultado:
```text
┌────────────┐ ┌────────────┐ ┌────────────┐
│ Guelaguetza│ │ Jazz       │ │ Mezcal     │
└────────────┘ └────────────┘ └────────────┘

┌────────────┐
│ Día Muertos│
└────────────┘
```

## 9. `repeat()`

Esto:
```css
grid-template-columns: repeat(3, 1fr);
```

es equivalente conceptualmente a:
```css
grid-template-columns: 1fr 1fr 1fr;
```

Y:
```css
repeat(4, 1fr);
```

sería:
```css
1fr 1fr 1fr 1fr
```

Esto es muy común en CSS moderno.

## 10. Grid responsive

Ahora podemos hacer algo muy interesante:
```css
.events {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}
```

En escritorio:
```text
┌──────┐ ┌──────┐ ┌──────┐
│  A   │ │  B   │ │  C   │
└──────┘ └──────┘ └──────┘
```

Y posteriormente, mediante una media query:
```css
@media (max-width: 768px) {
    .events {
        grid-template-columns: 1fr;
    }
}
```

En móvil:
```text
┌─────────────────┐
│       A         │
└─────────────────┘

┌─────────────────┐
│       B         │
└─────────────────┘

┌─────────────────┐
│       C         │
└─────────────────┘
```

Esto nos introduce formalmente a otro tema del roadmap:

**Responsive Design**.

Pero todavía no quiero profundizar en media queries; primero quiero que entiendas bien Grid.

## 11. Flexbox vs Grid

Esta es una de las preguntas más importantes que debes aprender a responder como frontend developer.

**Flexbox**

Piensa:

> **"Quiero distribuir elementos en una dimensión."**

Por ejemplo:
```text
→ → → →
```

o:
```text
↓
↓
↓
```

Un header:
```text
Logo    Inicio    Explorar    Perfil
```

Una fila de botones:
```text
[Guardar] [Compartir] [Comentar]
```

Una columna de elementos:
```text
Perfil
↓
Descripción
↓
Botones
```

### Grid

Piensa:

> "Quiero controlar filas y columnas."

Por ejemplo:
```text
┌───────┬───────┬───────┐
│   A   │   B   │   C   │
├───────┼───────┼───────┤
│   D   │   E   │   F   │
└───────┴───────┴───────┘
```

Una galería de imágenes.

Una cuadrícula de eventos.

Un layout de:
```text
Sidebar + contenido
```

## 🧠 Una regla práctica

No la tomes como una ley absoluta, pero inicialmente puedes pensar:
```text
Flexbox
    ↓
componentes / elementos
    ↓
una dimensión


Grid
    ↓
layout / estructura
    ↓
dos dimensiones
```

Y algo muy importante:

> **Flexbox y Grid no compiten entre sí. Se pueden utilizar juntos**.

Por ejemplo, Viajia podría tener:
```text
Página
 │
 ├── Grid
 │    ├── Sidebar
 │    └── Contenido
 │
 └── Contenido
      │
      └── Flexbox
           ├── Botón
           ├── Botón
           └── Botón
```

Incluso un elemento Grid puede contener un Flexbox y viceversa.
