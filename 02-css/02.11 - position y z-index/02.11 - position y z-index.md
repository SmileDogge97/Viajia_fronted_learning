# 02.11- `position` y `z-index`

Ahora vamos a aprender algo muy importante para interfaces web: **cómo sacar elementos del flujo normal de la página y colocarlos respecto a otros elementos**.

Esto nos servirá posteriormente para cosas como:

- menús desplegables;
- botones flotantes;
- badges sobre imágenes;
- overlays;
- modales;
- elementos superpuestos;
- barras de navegación;
- componentes que aparecen encima de otros.

## 1. El flujo normal

Por defecto, los elementos HTML siguen el **normal flow**.

Por ejemplo:
```html
<div>Elemento A</div>
<div>Elemento B</div>
<div>Elemento C</div>
```

El navegador los coloca:
```text
┌─────────────┐
│ Elemento A  │
└─────────────┘
┌─────────────┐
│ Elemento B  │
└─────────────┘
┌─────────────┐
│ Elemento C  │
└─────────────┘
```

Cada elemento ocupa su espacio y afecta la posición de los siguientes.

## 2. `position`

CSS tiene diferentes valores para `position`:
```text
static
relative
absolute
fixed
sticky
```

El valor predeterminado es:
```css
position: static;
```

## 3. `position: relative`
```css
.event-card {
    position: relative;
}
```

Por sí mismo puede parecer que no cambia nada.

La importancia aparece cuando tenemos un elemento hijo con:
```css
position: absolute;
```

Por ejemplo:
```html
<article class="event-card">

    <img src="guelaguetza.jpg">

    <span class="event-badge">
        GRATIS
    </span>

</article>
```

Podemos hacer:
```css
.event-card {
    position: relative;
}

.event-badge {
    position: absolute;
    top: 10px;
    right: 10px;
}
```

Resultado conceptual:
```text
┌──────────────────────────────┐
│                    ┌───────┐ │
│     Imagen         │GRATIS │ │
│                    └───────┘ │
│                              │
│       Guelaguetza            │
└──────────────────────────────┘
```

Aquí `relative` está funcionando como **referencia de posicionamiento** para el elemento `absolute`.

## 4. `position: absolute`

Cuando hacemos:
```css
.event-badge {
    position: absolute;
    top: 10px;
    right: 10px;
}
```

el elemento sale del flujo normal.

Podemos controlar su posición utilizando:
```text
top
right
bottom
left
```

Por ejemplo:
```css
top: 10px;
right: 10px;
```

significa aproximadamente:

> Colócate 10px desde la parte superior y 10px desde la derecha de tu elemento de referencia.

## 5. ¿Por qué `relative` y `absolute` suelen aparecer juntos?

Este patrón:
```css
.parent {
    position: relative;
}

.child {
    position: absolute;
}
```

es extremadamente común.

Podemos pensar:
```text
parent
└── establece el sistema de coordenadas
        ↓
child
└── se posiciona dentro de ese sistema
```

En Viajia podríamos utilizarlo para:
```
┌────────────────────────────┐
│                    ♥       │ ← botón favorito
│                            │
│        Imagen evento       │
│                            │
└────────────────────────────┘
```

## 6. `z-index`

Ahora imagina que dos elementos se superponen.
```text
┌───────────────┐
│     A         │
│      ┌──────────────┐
│      │      B       │
│      │              │
└──────┴──────────────┘
```

¿Cuál queda encima?

Ahí entra:
```css
z-index
```

Por ejemplo:
```css
.element-a {
    z-index: 1;
}

.element-b {
    z-index: 2;
}
```

Generalmente:
```text
z-index: 2
       ↑
       │
queda encima
       │
z-index: 1
```

Una forma sencilla de imaginarlo es como **capas**:
```text
        ┌─────────────┐
        │ z-index: 3  │
        └─────────────┘
      ┌─────────────────┐
      │   z-index: 2    │
      └─────────────────┘
    ┌─────────────────────┐
    │     z-index: 1      │
    └─────────────────────┘
```

## 7. `position: fixed`

Ahora tenemos:
```css
position: fixed;
```

El elemento queda fijado respecto al viewport.

Por ejemplo:
```css
.help-button {
    position: fixed;
    right: 20px;
    bottom: 20px;
}
```

Podríamos tener:
```text
┌────────────────────────────────┐
│ Viajia                         │
│                                │
│       Contenido                │
│                                │
│                                │
│                                │
│                         ┌────┐ │
│                         │ ?  │ │
│                         └────┘ │
└────────────────────────────────┘
```

Aunque hagamos scroll, el botón permanece en esa posición respecto a la pantalla.

Esto podría utilizarse, por ejemplo, para un botón flotante.

## 8. `position: sticky`

Este es particularmente interesante para interfaces.
```css
.navigation {
    position: sticky;
    top: 0;
}
```

El elemento inicialmente participa en el flujo normal, pero al hacer scroll puede quedarse "pegado" en determinada posición.

Conceptualmente:
```text
Antes del scroll:

┌─────────────────┐
│ Navbar          │
├─────────────────┤
│ Contenido       │
│                 │
│                 │
└─────────────────┘


Después del scroll:

┌─────────────────┐
│ Navbar          │ ← permanece aquí
├─────────────────┤
│ Contenido       │
│                 │
│                 │
└─────────────────┘
```

Esto puede ser útil para una navegación de Viajia.

## 🧪 Ejercicio

Vamos a hacer algo que podría existir perfectamente en una tarjeta de evento de Viajia.

HTML:
```html
<article class="event-card">

    <img
        src="imagen_guelaguetza.jpg"
        alt="Imagen de la Guelaguetza"
    >

    <span class="event-badge">
        NUEVO
    </span>

    <h2>Guelaguetza</h2>

</article>
```

Queremos obtener algo parecido a:
```text
┌──────────────────────────────┐
│                    ┌───────┐ │
│                    │ NUEVO │ │
│       IMAGEN       └───────┘ │
│                              │
│                              │
├──────────────────────────────┤
│ Guelaguetza                  │
└──────────────────────────────┘
```

Intenta conseguirlo utilizando:
```text
position: relative
position: absolute
top
right
```
