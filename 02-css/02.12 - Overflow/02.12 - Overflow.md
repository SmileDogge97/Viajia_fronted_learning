# 02.12 - `overflow`
Ya conocemos el Box Model, así que ahora vamos a ver qué ocurre cuando el contenido de un elemento es más grande que el espacio disponible.

## 1. El problema

Supongamos:
```html
<div class="event-card">
    <p>
        Esta es una descripción bastante larga de un evento
        que ocupa mucho más espacio del disponible.
    </p>
</div>
```

Y:
```css
.event-card {
    width: 300px;
    height: 100px;
}
```

El contenido puede terminar desbordándose:
```text
┌─────────────────────────┐
│ Esta es una descripción │
│ bastante larga de un    │
│ evento que ocupa mucho  │
└─────────────────────────┘
  │
  │ contenido que continúa
  ▼
```

CSS nos permite controlar ese comportamiento mediante `overflow`.

## 2. overflow: visible

Es el comportamiento predeterminado.
```css
.event-card {
    overflow: visible;
}
```

El contenido que excede las dimensiones del elemento **sigue siendo visible**.
```text
┌───────────────┐
│ Contenido     │
│ Contenido     │
└───────────────┘
  Contenido que
  se desborda
```

## 3. `overflow: hidden`
```css
.event-card {
    overflow: hidden;
}
```

Todo lo que salga de los límites del elemento queda oculto.
```text
┌───────────────┐
│ Contenido     │
│ Contenido     │
└───────────────┘
```

Esto es muy común en interfaces modernas.

Por ejemplo, imagina una imagen dentro de una tarjeta:
```css
.event-card {
    border-radius: 12px;
    overflow: hidden;
}
```

Si la imagen toca los bordes:
```text
┌─────────────────────┐
│       IMAGEN        │
│                     │
│                     │
├─────────────────────┤
│ Guelaguetza         │
└─────────────────────┘
```

el `overflow: hidden` evita que la imagen sobresalga de las esquinas redondeadas.

## 4. `overflow: auto`
```css
.event-card {
    overflow: auto;
}
```

Si el contenido **no cabe**, el navegador puede proporcionar barras de desplazamiento.
```text
┌────────────────────┐
│ Contenido          │█
│ Contenido          │█
│ Contenido          │█
│ Contenido          │▼
└────────────────────┘
```

Pero si el contenido cabe, no necesitas mostrar una barra innecesariamente.

Por eso `auto` suele ser más apropiado que `scroll` cuando queremos desplazamiento solamente cuando sea necesario.

## 5. `overflow: scroll`
```css
.event-card {
    overflow: scroll;
}
```

Indica que el elemento debe proporcionar mecanismos de desplazamiento, incluso aunque el contenido no necesariamente los necesite.

En interfaces modernas normalmente preferiremos `auto` cuando queremos que el scroll aparezca únicamente cuando haga falta.

## 6. Ejes independientes

También podemos controlar cada eje por separado:
```css
overflow-x: auto;
overflow-y: hidden;
```

Por ejemplo:
```text
horizontal → permitido
vertical    → oculto
```

Esto puede ser útil para componentes como:
```text
Eventos recomendados →

┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│      │ │      │ │      │ │      │ →
└──────┘ └──────┘ └──────┘ └──────┘
```

En móvil podríamos tener una lista horizontal de tarjetas.

## 🧠 Algo importante: `overflow` no solamente significa "hacer scroll"

Ese es un error común al empezar.

`overflow` realmente responde a:

> ¿Qué hacemos con el contenido que excede los límites de su caja?

Podemos:
```text
visible → dejarlo salir
hidden  → ocultarlo
auto    → desplazamiento si hace falta
scroll  → permitir desplazamiento
```

## 🧪 Ejercicio

Vamos a hacer una tarjeta de Viajia.

**HTML**
```html
<article class="event-card">

    <div class="event-image">
        <img
            src="guelaguetza.jpg"
            alt="Guelaguetza"
        >
    </div>

    <div class="event-content">
        <h2>Guelaguetza</h2>

        <p>
            Festival cultural tradicional de Oaxaca con
            música, danza y gastronomía regional.
        </p>
    </div>

</article>
```

**CSS inicial**
```css
.event-card {
    width: 300px;
    height: 300px;
    border: 2px solid black;
}

.event-image {
    height: 150px;
}

.event-image img {
    width: 100%;
    height: 100%;
}
```

Primero observa qué sucede sin utilizar `overflow`.

Después prueba:
```css
.event-image {
    height: 150px;
    overflow: hidden;
}
```
