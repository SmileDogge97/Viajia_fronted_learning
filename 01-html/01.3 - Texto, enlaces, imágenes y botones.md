# 01.3 Texto, enlaces, imágenes y botones

## 1. Encabezados: `h1` a `h6`
Ya utilizaste:
```html
<h1>Descubre Oaxaca</h1>
```

HTML proporciona seis niveles:
```html
<h1>Encabezado 1</h1>
<h2>Encabezado 2</h2>
<h3>Encabezado 3</h3>
<h4>Encabezado 4</h4>
<h5>Encabezado 5</h5>
<h6>Encabezado 6</h6>
```

Representan una jerarquía de encabezados.

Por ejemplo:
```text
h1 → Página
 │
 ├── h2 → Sección
 │    ├── h3 → Subsección
 │    └── h3 → Subsección
 │
 └── h2 → Otra sección
      └── h3 → Subsección
```

Para Viajia:

```html
<h1>Descubre Oaxaca</h1>

<section>
    <h2>Eventos cercanos</h2>

    <article>
        <h3>Guelaguetza</h3>
    </article>

    <article>
        <h3>Festival de Jazz</h3>
    </article>
</section>
```

Esto describe una jerarquía lógica.

**⚠️ No utilices encabezados para controlar tamaños**

No hagas:
```html
<h1>Texto pequeño</h1>
```

solamente porque quieres que el texto sea grande.

La apariencia la controlaremos posteriormente con CSS.

## 2. `<p>`  Párrafos
`p` representa un párrafo:

```html
<p>
    Encuentra eventos, lugares y experiencias cerca de ti.
</p>
```

Es uno de los elementos más básicos para contenido textual.

Y aquí aparece una diferencia importante respecto a un div.

Esto:
```html
<div>
    Encuentra eventos...
</div>
```

no significa semánticamente:

`"Este es un párrafo."`

Mientras que:
```html
<p>
    Encuentra eventos...
</p>
```

sí lo expresa.

## 3. `<strong>` — Importancia
`strong` indica que un fragmento de contenido tiene **gran importancia o relevancia**.

Por ejemplo:

```html
<p>
    <strong>Importante:</strong>
    El evento comienza a las 18:00.
</p>
```

El navegador normalmente lo muestra en negritas.

Pero nuevamente:

`No deberíamos pensar en strong como "poner texto en negritas".`

Su función principal es **semántica**.

CSS puede cambiar completamente su apariencia.

## 4. `<em>` — Énfasis
`em` representa énfasis:

```html
<p>
    Este evento es <em>especialmente recomendado</em>
    para familias.
</p>
```

Normalmente se representa en cursiva.

Pero nuevamente:
```text
strong → importancia
em → énfasis
```

no:
```text
strong → bold
em → italic
```

La apariencia predeterminada es solamente una consecuencia del estilo que el navegador aplica por defecto.

## 5. Enlaces: `<a>`
Ya utilizaste:

```html
<a href="/Explorar">Explorar</a>
```

`a` representa un **hipervínculo**.

Su propósito es llevar al usuario hacia otro recurso o ubicación.

Por ejemplo:
```html
<a href="/explore">
    Explorar eventos
</a>
```

El atributo fundamental aquí es:
```html
href="/explore"
```
`href` indica el destino del enlace.

### 6. Tipos de URLs: `href`
Podemos tener una URL relativa:
```html
<a href="/explore">Explorar</a>
```

o:
```html
<a href="/events/123">
    Ver evento
</a>
```

También una URL absoluta:
```html
<a href="https://example.com">
    Visitar sitio
</a>
```

Y podemos apuntar a un correo:
```html
<a href="mailto:contacto@example.com">
    Contactar
</a>
```

O un teléfono:
```html
<a href="tel:+521234567890">
    Llamar
</a>
```

## 7. Enlace vs botón
Este concepto quiero que lo entiendas especialmente bien.

Supongamos que queremos algo que diga:

`Explorar eventos`

Podríamos hacer:
```html
<a href="/events">
    Explorar eventos
</a>
```

o:
```html
<button>
    Explorar eventos
</button>
```

Pueden terminar viéndose idénticos gracias a CSS.

Pero **no significan lo mismo**.

`a`

Representa navegación:

`"Llévame a otro recurso."`

```html
<a href="/events">
    Explorar eventos
</a>
```

`button`

Representa una acción:

`"Haz algo."`

```html
<button>
    Mostrar filtros
</button>
```

Por ejemplo:
```text
Usuario
  │
  ├── Explorar
  │     ↓
  │   Navegar
  │
  └── Mostrar filtros
        ↓
      Acción
```

Esta distinción será **muy importante en React**, especialmente para accesibilidad y comportamiento.

## 8. Imágenes: `<img>`
Ya utilizaste:

```html
<img
    src="avatar.jpg"
    alt="Avatar"
>
```

Aquí tenemos dos atributos fundamentales.

### `src`
```html
src="avatar.jpg"
```

Indica dónde está la imagen.

Puede ser:
```html
<img src="avatar.jpg">
```

o una URL:
```html
<img src="https://example.com/image.jpg">
```

### `alt`
```html
alt="Avatar"
```

Proporciona un texto alternativo.

Este atributo es **muy importante para accesibilidad**.

## 9. ¿Por qué existe alt?
Imagina que tenemos:
```html
<img
    src="guelaguetza.jpg"
    alt="Danza tradicional durante la Guelaguetza en Oaxaca"
>
```

Una persona que no puede ver la imagen puede recibir esa descripción mediante una tecnología de asistencia.

Además, si la imagen no puede cargarse, el texto alternativo puede proporcionar información al usuario.

Por eso no deberíamos hacer simplemente:
```html
<img src="guelaguetza.jpg">
```

cuando la imagen tiene información relevante.

## 10. ¿Y si la imagen es puramente decorativa?
Supongamos que tenemos una imagen que solamente sirve como decoración.

Podemos utilizar:
```html
<img src="decoracion.png" alt="">
```

El `alt` vacío indica que **no necesitamos proporcionar información sobre esa imagen** a tecnologías de asistencia.

Esto evita que un lector de pantalla anuncie información innecesaria.

## 11. Atributos HTML
Ya has utilizado varios:
```html
<html lang="es">
```
```html
<meta charset="UTF-8">
```
```html
<a href="/explore">
```
```html
<img src="avatar.jpg" alt="Avatar">
```

Un atributo proporciona información adicional sobre un elemento.

La estructura general es:
```html
<elemento atributo="valor">
```

Por ejemplo:
```html
<a href="/events">
```

tenemos:

```text
elemento → a
atributo → href
valor → /events
```

Un elemento puede tener varios:
```html
<img
    src="guelaguetza.jpg"
    alt="Danza tradicional de la Guelaguetza"
>
```

## 12. Atributos booleanos
Hay atributos que funcionan como un estado verdadero/falso.

Por ejemplo:
```html
<button disabled>
    Comprar
</button>
```

`disabled` indica que el botón está deshabilitado.

También existen:
```html
<input required>
<input checked>
<input autofocus>
```

No necesitas estudiarlos todos todavía.

Solo quiero que conozcas el concepto.

## 13. Un pequeño ejemplo de Viajia

Imaginemos una tarjeta de evento:

```html
<article>

    <img
        src="guelaguetza.jpg"
        alt="Danza tradicional durante la Guelaguetza"
    >

    <h3>Guelaguetza</h3>

    <p>
        Disfruta de una de las celebraciones culturales
        más importantes de Oaxaca.
    </p>

    <p>
        <strong>15 de septiembre</strong>
    </p>

    <a href="/events/guelaguetza">
        Ver evento
    </a>

</article>
```

Observa cómo cada elemento tiene un propósito:
```text
article
│
├── img       → imagen
├── h3        → título
├── p         → descripción
├── p         → información
└── a         → navegación
```

No estamos pensando todavía en:

`"¿Cómo se ve?"`

Estamos pensando:

`"¿Qué representa cada cosa?"`

Esa mentalidad nos ayudará muchísimo cuando lleguemos a CSS.
