# Anatomía de un documento HTML

## 1. ¿Qué es HTML?

HTML significa:

**HyperText Markup Language**

Es un **lenguaje de marcado**, no un lenguaje de programación.

---

## 2. Estructura básica de un documento HTML

```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Viajia</title>
</head>
<body>

    <h1>Bienvenido a Viajia</h1>

</body>
</html>
```

---

**Partes principales de un HTML**
### 2.1 `<!DOCTYPE html>`

Esto indica al navegador que estamos utilizando **HTML5**.

No es exactamente una etiqueta HTML.

Es una declaración que le indica al navegador cómo debe interpretar el documento.

```html
<!DOCTYPE html>
```

Esto ayuda a que el navegador interprete correctamente la página y use el modo estándar.

### 2.2 `<html>`

```html
<html lang="es">
```

Es **la raíz del documento HTML**. 
Todo el contenido de la página debe ir dentro de esta etiqueta.
```html
<html>
    ...
</html>
```

El atributo `lang` indica el idioma principal del contenido. En este caso, `es` significa español.

#### ¿Por qué importa?

Entre otras cosas, ayuda a:
- tecnologías de asistencia;
- lectores de pantalla;
- motores de búsqueda;
- interpretación del idioma.


### 3. `<head>`

```html
<head>
    ...
</head>
```

`head` contiene información sobre el documento, no el contenido principal que queremos mostrar al usuario.

Por ejemplo:

```html
<head>
    <meta charset="UTF-8">
    <title>Viajia</title>
</head>
```

Aquí podemos colocar:
- metadata;
- título de la página;
- configuración del viewport;
- referencias a CSS;
- iconos;
- información para motores de búsqueda;
- etc.

Una forma sencilla de recordarlo:
```html
<head>
    Información SOBRE el documento
</head>
```

### 4. `<body>`
Después tenemos:
```html
<body>
    ...
</body>
```

Aquí estará el contenido que forma nuestra aplicación/página.

Por ejemplo:

```html
<body>

    <h1>Eventos cercanos</h1>

    <p>Encuentra qué hacer en tu ciudad.</p>

    <button>Explorar eventos</button>

</body>
```

Puedes pensar:
```text
HTML
│
├── HEAD
│   └── Información sobre el documento
│
└── BODY
    └── Contenido de la aplicación
```

---

### head != header
Esto es muy importante porque sus nombres pueden confundirte.

Tenemos:
```html
<head>
```
y:
```html
<header>
```

No son lo mismo.

`<head>`

Contiene metadata del documento.

```html
<head>
    <title>Viajia</title>
</head>
```

`<header>`
Es un elemento visible que representa contenido introductorio o navegación.

```html
<header>
    <nav>
        ...
    </nav>
</header>
```

Por ejemplo, una página de Viajia podría terminar teniendo:

```text
HTML
│
├── head
│
└── body
    │
    ├── header
    │
    ├── main
    │
    └── footer
```
---

### 8. Elementos y etiquetas
Observa:

```html
<h1>Eventos cercanos</h1>
```

Tenemos una etiqueta de apertura:

```html
<h1>
```

contenido:

Eventos cercanos

y una etiqueta de cierre:

```html
</h1>
```

El conjunto:

```html
<h1>Eventos cercanos</h1>
```

es un **elemento HTML**.

Podemos representarlo:

```text
Elemento
│
├── etiqueta de apertura
│
├── contenido
│
└── etiqueta de cierre
```

---

### 9. Elementos anidados

Los elementos pueden contener otros elementos.

Por ejemplo:
```html
<body>

    <main>

        <h1>Eventos cercanos</h1>

        <p>
            Encuentra eventos cerca de ti.
        </p>

    </main>

</body>
```

Tenemos:
```text
body
└── main
    ├── h1
    └── p
```

Esto será **fundamental** para CSS posteriormente.

Cuando lleguemos al DOM, esta estructura te resultará muy familiar.

---

### 10. Atributos

Los elementos pueden tener información adicional mediante **atributos**.

Por ejemplo:
```html
<html lang="es">
```

Tenemos:
```text
Elemento: html
Atributo: lang
Valor: es
```

Otro ejemplo:
```html
<a href="https://example.com">
    Visitar sitio
</a>
```

Aquí:
```text
Elemento: a
Atributo: href
Valor: https://example.com
```

Los atributos normalmente aparecen en la etiqueta de apertura:
```html
<elemento atributo="valor">
```

### 11. Elementos sin contenido

No todos los elementos necesitan etiqueta de cierre.

Por ejemplo:
```html
<img src="avatar.jpg" alt="Foto de perfil">
```

No hacemos:
```html
<img></img>
```

Lo mismo ocurre con elementos como:
```html
<br>
<hr>
<meta>
<link>
<input>
```

Estos se conocen comúnmente como void elements.

```html
<!DOCTYPE html>
<html lang="es">

    <meta charset="UTF-8">
    <title>Viajia - Explora tu destino</title>

  <body>

  </body>
</html>
```
